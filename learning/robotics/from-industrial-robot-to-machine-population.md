# Learning path: From industrial robot to machine population

## Learning goal
Understand why robotics spreads from structured factories into increasingly variable environments and how this can culminate in persistent machine populations on Earth and in space.

## Module 1 — Structured automation
Variables: repeatability, fixtures, deterministic geometry, cycle time.
Exercise: identify which environmental assumptions make a classic industrial robot reliable.

## Module 2 — Environment entropy
Variables: object variability, deformability, contamination, occlusion, human presence, task novelty.
Case: textile/workwear handling in Kolbermoor (2026).
Exercise: compare a rigid component with a deformable textile and enumerate perception/manipulation uncertainty.

## Module 3 — Perception + manipulation
Explain vision, pose/shape estimation, grasp planning, force feedback and failure recovery.
Exercise: choose sensors and end effectors for three increasingly unstructured tasks.

## Module 4 — Morphology
Compare specialized machines with humanoid/general-purpose platforms.
Key insight: ubiquitous robotics does not imply ubiquitous humanoids.

## Module 5 — Networks and swarms
Introduce distributed task allocation, local autonomy, communication loss and cooperative manipulation.
Bridge: MiniNode architecture.

## Module 6 — Space environments
Compare Earth, Moon, Mars and orbital habitats.
Parameters: radiation, vacuum/atmosphere, dust, thermal cycling, latency, maintenance cost, human labor scarcity.

## Module 7 — Machine population
Model robots as a persistent infrastructure population with lifecycle, energy, maintenance, ownership, work roles and interactions with humans.

## NOXIA transfer exercise
Design one settlement twice: first with robots as exceptional equipment, then with a machine population. Compare labor, buildings, logistics, energy, repair capacity and social space.
