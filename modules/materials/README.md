# Magnetismus & funktionale Materialien

Dieser SSF-Strang verbindet physikalische Grundlagen mit Materialwissenschaft und technischer Anwendung.

## Leitfrage

Warum verhalten sich Materialien magnetisch unterschiedlich, und wie wird aus atomaren Eigenschaften ein technischer Werkstoff?
