# Request
Develop the scientific/educational learning layer for the energy-grid causal chain defined by KUEPER Engineering authority `ENG-SYS-EGCA-0001` / `ENG-EGCA-r1`.

## Learning objectives
Explain why:
- installed generation capacity is not equal to currently available generation;
- available generation is not equal to transferable grid power;
- transferable power is not equal to deliverable power at a load;
- storage has separate power and energy limits;
- grid links, converters/substations, losses and protection can become bottlenecks;
- curtailment is distinct from generation failure;
- flexible loads and storage can improve utilization without creating new generation;
- microgrids, reserve and blackstart change resilience;
- siting and network reinforcement can move the bottleneck.

Use terrestrial examples first, then carefully contrast lunar, Mars and orbital cases without treating Engineering assumptions as scientific canon.
