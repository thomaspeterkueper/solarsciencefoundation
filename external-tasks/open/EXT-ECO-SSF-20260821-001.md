## Anlass

Solar Science Foundation should continuously discover and triage relevant new scientific evidence instead of depending only on manually introduced topics. The system must preserve the distinction between publication, evidence, accepted knowledge and curriculum impact.

## Gewünschte Änderung

Implement the smallest useful SSF Research Watch v0.1 following kueper-ecosystem/docs/architecture/SSF_RESEARCH_WATCH.md. First inspect SSF governance, current modules/paths/content and existing source-of-truth boundaries. Add configurable watch-topic and source registries; normalized persistent evidence/discovery records; DOI/arXiv/registry deduplication; relevance scoring; impact classification NEW/CONFIRMS/REVISES/CONTRADICTS/DEPRECATES/NO_IMPACT/UNCERTAIN; and bounded promotion into RESEARCH_DISCOVERY or CANON_VALIDATION TaskCandidates. Do not directly rewrite curriculum from discoveries. Emit cross-project requests only through valid KUEPER outbox envelopes. Preserve preprint/retraction/correction/evidence-type metadata and source provenance. Include deterministic fixtures/tests for duplicate discovery, no-impact classification and a validation candidate. Keep discovery adapters replaceable and do not hard-code provider/model identity. Add cost-policy metadata so expensive synthesis/review can be deferred off-peak.
